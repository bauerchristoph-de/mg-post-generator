# AI Post- & Design-Generator — Plugin-Marketplace

Privates Plugin-Repository. Zugriff = Lizenz.

## Installation (einmalig)

```
/plugin marketplace add bauerchristoph-de/mg-post-generator
/plugin install ai-post-generator@mg-post-generator
```

Auto-Update aktivieren. Erster Start: **„Richte den Post-Generator ein.“** — das Plugin erfasst Design-System und Brand Voice (bzw. übernimmt beides, wenn der AI Video-Cutter schon eingerichtet ist) und legt den Kundenordner an.
